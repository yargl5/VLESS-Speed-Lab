# VLESS Speed Lab

Локальный Windows‑софт для массовой проверки VLESS-конфигов через Xray-core.

Загрузите TXT-файл с несколькими VLESS-ссылками — программа проверит их по очереди и покажет, какой конфиг быстрее и стабильнее.

![VLESS Speed Lab — интерфейс](dashboard.png)

## Возможности

- проверка большого списка `vless://` конфигов;
- текущий конфиг и этап проверки в реальном времени;
- live‑скорость загрузки;
- скорость загрузки четырьмя параллельными потоками;
- HTTP latency/ping через VLESS-прокси;
- прогресс и время проверки;
- история запусков с датой, номером конфига, ping и скоростью;
- отдельные логи ошибок Xray и тестового запроса;
- загрузка конфигов через веб-интерфейс или вставка ссылок вручную;
- работа полностью локально на компьютере.

## Запуск Windows

1. Запустите `run_dashboard.bat`.
2. Откройте адрес, который появится в консоли, например:

   ```text
   http://127.0.0.1:8765
   ```

3. Во вкладке «Тест» загрузите TXT-файл или вставьте VLESS-ссылки.
4. Нажмите «Запустить тест».

Формат файла — одна ссылка `vless://` на строку. Пример находится в `configs.example.txt`.

## Что нужно для работы

- Windows 10/11;
- Python 3.9 или новее;
- `curl.exe` — обычно уже входит в Windows;
- Xray-core уже включён в этот репозиторий как `xray.exe`.

Дополнительные Python-библиотеки не нужны.

## Результаты

Программа создаёт локальные файлы:

- `vless_history_full.csv` — история всех запусков;
- `vless_logs/` — подробные логи по конфигам;
- `configs.txt` — сохранённый список конфигов.

Эти файлы исключены из Git через `.gitignore` и не должны попадать в публичный репозиторий.
